# Applications that use SeaweedFS

## [AvaloniaSyncer](https://github.com/SuperJMN/avaloniaSyncer)

AvaloniaSyncer is a cross-platform **file explorer** with folder synchronization and a simple and useful GUI. Supports SeaweedFS via **Filer**.

![image](https://github.com/seaweedfs/seaweedfs/assets/3109851/f9de1530-d34a-4d93-adeb-9c9fa861330a)

## [Cloud CCTV Storage Platform](https://github.com/evercam/evercam-media)

Cloud CCTV Storage Platform for [Evercam.io](https://evercam.io/) uses SeaweedFS server to save image files.

## [Email River Plugin](https://github.com/medcl/elasticsearch-river-email/)

Email River Plugin for Elasticsearch uses SeaweedFS server to save attachments.

## [lua-resty-weedfs](https://github.com/medcl/lua-resty-weedfs)

lua-resty-weedfs. A Nginx backend with weedfs and file post processing with ffmpeg and graphicsmagick by Medcl.
